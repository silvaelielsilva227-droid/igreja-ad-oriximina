# Igreja Assembleia de Deus · Extensão de Oriximiná

Sistema de gestão da igreja em Curuá – PA (Tv. Ten-Cel. Josino Cardoso Monteiro – Planalto).

- **Site:** https://silvaelielsilva227-droid.github.io/igreja-ad-oriximina/
- **Apps (Windows .exe e Android .apk):** aba [Releases](https://github.com/silvaelielsilva227-droid/igreja-ad-oriximina/releases/latest)

## Funções
- Painel com próximo culto, contagem regressiva, gráficos e aniversariantes
- Agenda automática de cultos (EBD, Senhoras, Senhores, Celebração, Ceia, Treinamento, Oração, Círculo de Oração)
- Dízimos, ofertas, despesas, recibos e relatórios
- Perfil completo de cada membro (foto, dados, vida cristã, contribuições, participação)
- Eventos, notificações da programação e busca rápida (Ctrl+K)
- Contas de acesso: Administrador, Pastor/Pastora, Tesoureiro(a), Secretário(a) e Membro

## Tecnologia
HTML, CSS e JavaScript puro · Firebase Authentication + Cloud Firestore · GitHub Pages ·
Electron (Windows) e Capacitor (Android) gerados pelo GitHub Actions.
